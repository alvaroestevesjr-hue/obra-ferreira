# Obra Ferreira · Gestão da obra

Página da obra (Lote 02, Quadra D, Lagoa das Garças, Cambuí/MG): checklist, cronograma, medições, pagamentos, contratos, documentos e projetos em pastas, e visualizadores de IFC e DWG/DXF.

- Página: GitHub Pages (index.html)
- Dados: planilha do Google, lida e gravada pelo Apps Script em apps-script/Code.gs
- Arquivos enviados: pasta "Obra Ferreira · Arquivos" no Google Drive
- data.json: cópia dos dados usada enquanto a planilha não está conectada
- vendor/: bibliotecas dos visualizadores (three.js, web-ifc, dxf-viewer, libredwg-web)
